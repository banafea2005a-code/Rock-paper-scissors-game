# Rock Paper Scissors Game

A simple **Rock, Paper, Scissors** desktop game built with **C#** and **Windows Forms** on **.NET Framework 4.8**.

## Overview

The player chooses Rock, Paper, or Scissors. The computer randomly selects one of the three options, and the game compares both choices to determine the result.

## Features

- Player choices: Rock, Paper, and Scissors.
- Random computer selection.
- Displays the player's and computer's choices using images.
- Determines whether the player wins, the computer wins, or the round is a draw.
- Disables the choice buttons after a round until the player resets the game.
- Displays a result message and provides a reset button.

## Technologies

- C#
- Windows Forms
- .NET Framework 4.8
- Visual Studio
- Windows Forms controls, including buttons, labels, and picture boxes

## Rules

| Player's choice | Computer's choice | Result |
|---|---|---|
| Rock | Scissors | Player wins |
| Paper | Rock | Player wins |
| Scissors | Paper | Player wins |
| Same choice | Same choice | Draw |
| Any other combination | — | Computer wins |

## How to Run

1. Install **Visual Studio** with the **.NET desktop development** workload.
2. Open `Rock-paper-scissors game.sln` in Visual Studio.
3. Allow Visual Studio to load the project.
4. Build the solution.
5. Run the application using **Start** or `F5`.

The project targets **.NET Framework 4.8**, so make sure the required developer pack is available if Visual Studio asks for it.

## How to Play

1. Start the application.
2. Choose Rock, Paper, or Scissors.
3. The computer makes its choice automatically.
4. Review the displayed choices and result.
5. Click **Reset** to play another round.

## Main Code

- `Program.cs`: Starts the Windows Forms application.
- `Form1.cs`: Contains the game logic, random computer choice, winner checking, image updates, and reset behavior.
- `Form1.Designer.cs`: Contains the Windows Forms UI layout generated by Visual Studio.
- `Properties/Resources.resx`: Stores application resources used by the project.

## Learning Goals

This project is useful for practicing:

- C# enums and conditional statements.
- Random selection.
- Event handling in Windows Forms.
- Working with buttons, labels, and `PictureBox` controls.
- Separating game state from UI actions.

## Notes

- This is a local desktop game; it does not require a database or internet connection.
- The project archive contains Visual Studio-generated folders such as `.vs`, `bin`, and `obj`. These normally should not be committed to GitHub; use a suitable `.gitignore` file.
- The current implementation increments the displayed score when the player wins. If you want a full match score, you can extend the logic to track computer wins and draws as well.
